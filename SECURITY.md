# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |

## Reporting a Vulnerability

The `git-agecrypt` project takes the security of transparent secret management seriously. If you discover a vulnerability or potential security flaw, please do not file a public GitHub issue.

Report security issues through the repository's **GitHub Private Vulnerability Reporting** channel: open the **Security** tab at https://github.com/Crynspier/git-agecrypt/security and select **Report a vulnerability**. Do not file a public issue or include secret material in a public discussion.

Include the affected v0.5.0 commit or release, impact, reproduction steps, and a minimal proof of concept. If the private reporting button is unavailable, contact the repository owner through the GitHub account at https://github.com/Crynspier rather than disclosing details publicly.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will assess the impact and severity of the reported issue.
- **Fix & Disclosure:** If validated, we will prepare a patch and coordinate a disclosure timeline before releasing a security advisory.

Thank you for helping keep `git-agecrypt` and its users safe.
