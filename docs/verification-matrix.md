# Verification Matrix

This document maps every core security, durability, concurrency, format-compatibility, and server-enforcement invariant in `git-agecrypt` to the automated test suites and CI gates that verify it.

| Invariant Category | Specific Guarantee | Verification Suite / Test Target |
| :--- | :--- | :--- |
| **1. Recovery & Mutation Lock (`recovery.lock`)** | Exclusive OS lock (`flock` / `LockFileEx`), bounded timeout (`GIT_AGECRYPT_LOCK_TIMEOUT_MS`), automatic kernel release on `SIGKILL`/`TerminateProcess`, no PID/mtime heuristic reclamation, coordination-path replacement protection, continuous lock hold across `init`/`add-recipient`/`remove-recipient`/`rekey`/`rewrap`/`unlock`/`lock`/`migrate`, and scoped-ring lock recovery. | [`tests/test_recovery_lock_contract.rs`](../tests/test_recovery_lock_contract.rs), [`tests/test_concurrency.rs`](../tests/test_concurrency.rs), [`tests/test_mixed_concurrency_stress.rs`](../tests/test_mixed_concurrency_stress.rs) |
| **2. Format Version 1 & Fail-Closed Compatibility** | Explicit `.git-agecrypt/format` (`1`) and implicit v1 compatibility; fail-closed rejection on unknown/higher format versions (`2`, `99`), malformed `repo.pub`, corrupted `keys/*.age` envelopes, or malformed `lock.journal`. | [`tests/test_format_and_recovery_fixtures.rs`](../tests/test_format_and_recovery_fixtures.rs) |
| **3. Diagnostics (`inspect`) & Interop Recovery (`export-age`)** | Read-only `git-agecrypt inspect --format text\|json` reports format version, unsupported fields, recipient envelopes, key state, worktree/index states, and recovery actions; `git-agecrypt export-age` exports standard `age` files without writing plaintext to stdout; clean-room recovery works using only standard `age` primitives. | [`tests/test_format_and_recovery_fixtures.rs`](../tests/test_format_and_recovery_fixtures.rs) |
| **4. Server-Side `pre-receive` & CI Policy Enforcement** | `git-agecrypt check --pre-receive` and `--commit-range` (plus `examples/hooks/pre-receive`) inspect bare and non-bare repositories across branch creation, deletion, fast-forward pushes, force-pushes, merge commits, and multi-ref pushes; reject plaintext secrets, malformed `age` headers, unprotected secret renames, unsafe filenames, and missing ring metadata; support `--report-only` audit mode. | [`tests/test_server_enforcement.rs`](../tests/test_server_enforcement.rs), [`examples/hooks/pre-receive`](../examples/hooks/pre-receive) |
| **5. Crash Consistency & WAL Journal Replay** | Deterministic `SIGKILL`/`TerminateProcess` crash injection across 12 crash points during `unlock`, `lock`, `rekey`, and `remove-recipient` across linked worktrees preserves uncommitted plaintext edits and restores `repo.key` + worktree files without corruption. | [`tests/test_crash_matrix.rs`](../tests/test_crash_matrix.rs), [`tests/test_fault_injection.rs`](../tests/test_fault_injection.rs) |
| **6. Cryptographic Stream & Convergence Invariants** | `clean` -> `smudge` roundtrip identity, index-first and HMAC-SHA256 cache convergence, cache-poisoning detection, header-sniffing counter-trap, and O(1) memory spool (`>8 MiB` disk spillover). | `src/crypto.rs` unit & property tests (`cargo test --locked --lib`), [`tests/integration_tests.rs`](../tests/integration_tests.rs), [`tests/test_scale_and_binary.rs`](../tests/test_scale_and_binary.rs) |
| **7. Security Boundaries & Injection Defenses** | Rejects shell-unsafe secret filenames (`"`, `` ` ``, `$`, `\`, control chars), blocks `FORBIDDEN_ENV_VARS` (`LD_PRELOAD`, `PATH`, `GIT_SSH_COMMAND`, etc.) in `git-agecrypt run`, enforces `0600`/ACL on `repo.key`, enforces `PR_SET_DUMPABLE=0` on Linux `--fd`, and rejects symlink/reparse swaps on metadata. | [`tests/test_security_audit.rs`](../tests/test_security_audit.rs), [`tests/test_adversarial.rs`](../tests/test_adversarial.rs) |
| **8. Multi-Ring & Worktree Isolation** | Scoped rings (`--ring prod`) isolate keys, caches, and `.gitattributes` rules; `lock` and `unlock` synchronize across all linked worktrees and refuse to lock when a linked worktree is unreachable. | [`tests/test_worktrees_and_hooks.rs`](../tests/test_worktrees_and_hooks.rs), [`tests/test_edge_cases.rs`](../tests/test_edge_cases.rs) |
| **9. Fuzzing Harnesses** | Continuous structure-aware and byte-stream fuzzing of `clean`/`smudge`, 3-way merge conflict detection, `.env` parser, ring name validation, and format/journal/attribute parsers. | [`fuzz/fuzz_targets/`](../fuzz/fuzz_targets/) (`fuzz_clean_smudge`, `fuzz_merge_driver`, `fuzz_env_parser`, `fuzz_ring_validation`) |
